# View the database structure in a browser

Zoom in with the browser to see the details

## Usage

``` r
viewDatabaseModel(type = c("png"))
```

## Arguments

- type:

  Open the database model in either "png" or "svg".

## Value

Opens a internet browser window with the database model.

## Examples

``` r
if (FALSE) { # \dontrun{
viewDatabaseModel()
} # }
```
