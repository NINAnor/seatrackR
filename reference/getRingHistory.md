# Retrieve info on the ring history table

Read from the table of the history of ring numbers for birds that have
had their rings changed.

## Usage

``` r
getRingHistory(asTibble = FALSE)
```

## Arguments

- asTibble:

  Return result as tibble? Boolean.

## Value

Lazy query, or optionally a tibble

## Examples

``` r
if (FALSE) { # \dontrun{
getRingHistory()
} # }
```
