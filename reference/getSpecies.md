# Retrieve info on the registered species in the database

Retrieve info on the registered species in the database

## Usage

``` r
getSpecies(include_subspecies = FALSE)
```

## Arguments

- include_subspecies:

  Include subspecies in the output? Boolean

## Value

A tibble of the metadata.subspecies table

## Examples

``` r
if (FALSE) { # \dontrun{
getSpecies()
} # }
```
