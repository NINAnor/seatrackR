# IRMA positional data reference

Processed GLS data with missing locatations interpolated based on the
Informed Random Movement Algorithm (IRMA)

- #### **id**

  *type: string*

  Unique ID of position

- #### **date_time**

  *type: Date time at which position was recorded*

- #### **logger_id**

  *type: integer*

  Unique internal identfier of the logger

- #### **logger_model**

  *type: string*

  GLS logger model (e.g., c65, mk4083, etc.).

- #### **year_tracked**

  *type: string*

  Duration that the individual was instrumented with a logger
  (e.g. 2015_17).

- #### **session_id**

  *type: string*

  Unique ID for the logger deployment session during which this data was
  recorded.

- #### **individ_id**

  *type: string*

  Unique ID for each individual.

- #### **deployment_date**

  *type: date*

  Date when the logger was deployed.

- #### **retrieval_date**

  *type: date*

  Date when the logger was retrieved.

- #### **ring_number**

  *type: string*

  Metal ID ring number.

- #### **country_code**

  *type: string*

  Country/local code for metal ring.

- #### **species**

  *type: string*

  English name of the species.

- #### **colony**

  *type: string*

  Name of the colony where the logger was deployed and retrieved. Note
  that a SEATRACK colony name can cover several locations

- #### **col_lon**

  *type: float*

  Longitude of the colony.

- #### **col_lat**

  *type: float*

  Latitude of the colony.

- #### **loc_type**

  *type: string*

  Either GLS or IRMA, indicates whether this point is part of the
  original GLS positional data or generated by IRMA.

- #### **lon**

  *type: float*

  Longitude of position

- #### **lat**

  *type: float*

  Latitude of positon

- #### **sex**

  *type: string*

  Recorded sex at trapping event.

- #### **age_deployment**

  *type: string*

  Age of the bird at the time of deployment.

- #### **age_class_irma**

  *type: string*

  age_deployment reclassifed to be either “A” for an adult or “C”
  otherwise.

- #### **data_responsible**

  *type: string*

  Data owner or responsible person.

- #### **data_version**

  *type: integer*

  Version of the processing script used.
